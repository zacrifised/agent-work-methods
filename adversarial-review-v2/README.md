# 独立对抗复核

## 这是什么

对结论、方案或交付物做一次信息隔离的第二方挑刺，把「自己确认自己」升级成真正的独立复核。

## 什么时候用

结论要交付前；方案定了想找漏洞；需要独立第二意见时。

## 怎么装

把本目录放到你所用 agent 的 skill 目录（各产品位置不同，按其文档操作）。
本 skill 为纯文档，无 Python 依赖。

## 最小例子

把你的结论交给一个看不到你推理过程的复核者，只给它「对象 + 判据 + 排除项 + 输出格式」；拿到结论后只裁分歧，一致项不写进论证当支持证据。

## 文件说明

- `SKILL.md` — 方法本体：范围、完成判据、WHEN→THEN、硬规则、资源索引、反例
- `GLOSSARY.md` — 本方法用到的专有术语
`references/` — 信息隔离、模式、裁决规则
