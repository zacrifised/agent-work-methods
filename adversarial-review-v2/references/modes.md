# 五种模式的指令骨架

每条骨架只给输入，不给判定结果。占位符用 `<...>`，渲染前逐个替换。

## 1. 盲读校对

```
只读复核 <产物绝对路径>。不提供原文、不提供预期结果。
逐行标出可疑处：完整绝对路径 + 行号 + 原文片段 + 建议改法 + 把握度。
不预设错误数量与位置。不修改文件。
```

## 2. 反方案评审

```
只读需求与上下文：<路径清单>。不提供已有方案。
从零给出一个方案，并列出三个会让该方案失败的条件。
每个条件给可检验的观察量。不修改文件。
```

## 3. 事前验尸

```
只读方案：<路径>。假设它在半年后已经失败。
倒推最可能的五个原因，按「可观测信号 / 最早出现时间 / 事前可拦住的动作」列出。
不修改文件。
```

## 4. 红队挑刺

```
只读交付物：<路径清单>。输出挑刺判决书。
每条问题带齐：完整绝对路径 + 行号 + 原文片段 + 证据指针 + 翻盘条件
+ 严重度 + 修复成本量级 + 一句人话「在问什么」。
不预设问题数量。不修改文件。
```

## 5. 结论复核

```
只读原始证据：<路径清单>。不提供任何结论。
自行导出结论，并写出被排除的候选假设及其依据。
悬置项给判别实验。不修改文件。
```

## 输出要求

- 每条问题给完整绝对路径；无行号对象用「路径 + 对象标识 + 内容摘要」。
- 不写「双方一致」当支持证据。
- 不宣布放行。
