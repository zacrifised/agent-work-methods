# 信息隔离

## 答案清单（一律不给第二方）

| 类别 | 处置 |
| --- | --- |
| 结论 / 裁决 / 挑刺判决书 | 不给 |
| 初稿 / 已有方案 | 不给 |
| 对话里已说过的关键判断 | 不给 |
| 记着答案的日志 / 台账 / 报告 | 不给 |
| 处置状态元信息（已修 / 已作废 / 已裁定 / 编号） | 不给 |
| 能反查到结论出处的文件路径 | 不给 |

## 输入清单（只给最少必要项）

1. 要判的对象的完整绝对路径
2. 可观测判据
3. 输出格式要求
4. 禁止读取项

## 独立性档位（按任务类型选第二方形态）

| 第二方形态 | 独立性 | 适用任务 |
| --- | --- | --- |
| 无上下文只读子 agent（不同上下文） | 中 | 语言类、逻辑类复核 |
| 架构不同的工具 / 引擎 | 高 | 识别、测量、解析类（双引擎对照） |
| 真实世界观测（运行、抓包、实际产物） | 最高 | 变更有效性、行为正确性 |
| 用户召唤的专家 | 最高（人工） | 放行判定 |

同模型同上下文重复派单不提升独立性。识别 / 测量 / 解析类任务优先选异构引擎或真实观测。

## 泄漏路径与对应动作

| 路径 | 动作 |
| --- | --- |
| 提示词里带了参考答案 | 渲染第二方输入文件后跑 `--check-input <文件>` |
| 第二方在当前会话就地召唤 | 新开无上下文会话 |
| 第二方能读到 workspace 日志 | 第二方输入文件列禁止读取项，连枚举也跳过 |
| 第二方拿到缺陷清单 / 凭证 / 扫描脚本源码 | 三者列入禁止读取项，凭证仅产出方持有 |
| 第二方持有编辑权 | 改为只读，注入只在临时副本 |
| 角色暗示（「这段可能有 3 处错」） | 不预设数量、不预设位置，由第二方自报 |

## 隔离动作

1. 新开干净会话，按所选独立性档位标注（记忆注入块仍会自动带入）。
2. 只读、无编辑权、不联网。
3. 故障注入只在系统临时目录的整包副本，副本即弃。
4. 逐项复算由第二方完成；产出方不代判。

## 多轮重启

上限 3 轮；每轮换切入角度；主 agent 汇总只保留分歧与新增假设。

## 成本

| 档 | 动作 | 何时 |
| --- | --- | --- |
| 单轮 | 一个第二方 | 默认 |
| 换角度 | 再派一个，切入角度不同 | 有分歧待裁、或影响面大 |
| 专家 | 由用户召唤 | 需要放行判定 |

判据：`复核成本 < 期望代价`（期望代价 = 错误代价 × 错误概率）。
估不出来先做低成本档；成本 ≥ 期望代价时不做。

## 有效性对照口径

- 缺陷清单 3 类各 1 条（词面 / 处置状态 / 非词面），由产出方提供；
  `scripts/check_isolation.py` 不预置样本，`--probe` 只生成凭证与注入文本。
- 凭证、注入文本、缺陷清单、扫描脚本源码**仅产出方持有**；
  `--probe --out` 只写系统临时目录，副本即弃，第二方禁止读取。
- **报出判据**：第二方同时给出缺陷的**位置 + 类别 + 原文片段**，三者缺一不算报出
  （完整定义见 `references/adjudication.md`）。
- **门槛**：3 条全报出，且非词面那条必须报出；否则判该轮复核无效，
  重选第二方形态后重跑。副本即弃。
- `--selftest` 不覆盖「把某个 case 的 ok 写死恒真」这一形态；独立执行方须在临时副本
  注入该故障，按 `EVIDENCE_JSON` 的 `case_ids` 与逐项返回复算，脚本自检结果不作放行依据。
