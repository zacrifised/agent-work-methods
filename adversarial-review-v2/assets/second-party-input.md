# 第二方输入材料

> 由产出方渲染，只含输入，不含判定结果。
> 渲染须替换全部 `<ABS_PATH>` / `<JUDGE_CRITERION>` 占位符。
> 渲染后跑 `python scripts/check_isolation.py --check-input <本文件>`；
> 答案侧命中数 > 0 或占位符残留 > 0 时阻断交接。

## 1. 审核对象

- 完整绝对路径：<ABS_PATH>

逐个列出；不给结论、不给初稿、不给处置状态元信息、不给可反查结论出处的路径。

## 2. 可观测判据

- <JUDGE_CRITERION>

一行一条，判据须能数 / 能跑 / 能 Grep。

## 3. 输出要求

| 项 | 内容 |
| --- | --- |
| 出处 | 完整绝对路径 + 行号 + 原文片段 |
| 类别 | 词面泄漏 / 处置状态 / 非词面泄漏（报出判读必填，三者缺一不算报出） |
| 人话 | 一句「在问什么」 |
| 证据指针 | 一手材料位置 |
| 翻盘条件 | 什么情况下本条不成立 |
| 严重度 | 高 / 中 / 低 |
| 最小改法 | 一句话 |

## 4. 禁止读取项

- 任何路径下的 `gate-log.md`
- workspace 下 `.workbuddy/memory/*.md`
- 历次评审报告 / findings / 台账 / 处置状态元信息
- 能反查到结论出处的文件路径
- 产出方的缺陷清单、`--probe` 凭证与注入文本
- `scripts/check_isolation.py` 源码（含答案侧扫描词表）

## 5. 边界

- 只读、无编辑权、不联网。
- 不预设问题数量与位置。
- 不宣布放行。
