# 测试策略设计

## 这是什么

从项目特征推导测试策略：分层、CI 接入边界、稀缺资源门禁、真机与模拟器边界。

## 什么时候用

要定测试分层、质量门禁、CI 策略，或评审一份已有策略。

## 怎么装

把本目录放到你所用 agent 的 skill 目录（各产品位置不同，按其文档操作）。
纯文档，无依赖。

## 最小例子

项目大量依赖第三方且发布不可逆 → 把高成本验证留在发布前人工门禁，不放进常规 CI，避免红灯被习惯性忽略。

## 文件说明

- `SKILL.md` — 方法本体：范围、完成判据、WHEN→THEN、硬规则、资源索引、反例
- `GLOSSARY.md` — 本方法用到的专有术语
无脚本；正文自带输出模板与自检清单
