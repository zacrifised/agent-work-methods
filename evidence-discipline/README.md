# 证据纪律

## 这是什么

把「讲道理」变成可执行的检查：结论分级、先读后断、判别实验、何时停止追查。

## 什么时候用

排查问题、下结论、给数字、判断还值不值得继续追。

## 怎么装

把本目录放到你所用 agent 的 skill 目录（各产品位置不同，按其文档操作）。
纯文档，无依赖。

## 最小例子

准备说「问题出在 A」之前，先标这是【已证实】还是【推断】；如果是推断，附一个能证伪它的实验。

## 文件说明

- `SKILL.md` — 方法本体：范围、完成判据、WHEN→THEN、硬规则、资源索引、反例
- `GLOSSARY.md` — 本方法用到的专有术语
无脚本；正文自带 16 项开工检查
