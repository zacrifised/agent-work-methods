# 证据纪律

## 范围

覆盖：结论分级、先读后断、判别实验、以及何时停止追查。
不覆盖：假设空间搜索的完整流程（→ 排查方法论 skill）；跨领域原则真源（→ 方法论内核 skill）。

## 完成判据

- 开工 16 项检查逐条过；每项要么满足、要么写明不满足的原因
- 每条结论标【已证实】/【推断】/【未证实】；【推断】都附判别实验
- 无「互相印证 / 佐证」措辞；改为具体判别手段
- 报数字绑定场景 / 负载条件，给分布和峰值而非只有均值
- 被排除项与依据写出；悬置项给可执行判别手段（先过结案判据）
- 解释旧观察前做过时间轴核实（该变量在观察当时成立吗）
- 「吻合」声明核过独立测量链；功能在运行用 L3 实际交付层证据
- 任何工具失败都经过熔断四选一处理，不无处理进入下一步
- 准备输出「下一步判别实验」前过结案判据

## WHEN → THEN

**WHEN**：任务需要下结论、给数字、判「通不通 / 好不好 / 要不要换 / 还追不追」。
**THEN**：
1. 开工检查 16 项逐条过（能读的先读，单位/时区/滚动规则先校验）。
2. 候选 ≥2 个，含「看起来不可能」的；每个结论分级。
3. 执行中遇工具失败 → 熔断检查（同因 2 次即 STOP→DUMP→CLASSIFY→FIX→ESCALATE）。
4. 用「高频翻车点」表逐项排查相关项。
5. 判「功能在跑」先标定证据停在 L1 / L2 / L3 哪一层；只有 L3 能证明在工作。
6. 收尾前过结案判据 4 条；命中 ≥1 提出结案等用户决定，4 条全中直接停。
7. 用户感受与数据冲突 → 先怀疑取错窗口，再考虑记错；用户纠正优先复测。

## 开工检查 16 项

1. 该直接读的都读了吗？能读的不要推断（用户级路径用绝对路径，先确认存在再读）。
2. 时间 / 容量 / 速率字段：确认零点、单位、时区、日志滚动规则。
3. 候选假设列全了吗（≥2，含「看起来不可能」的）。
4. 每个结论标级了吗：【已证实】/【推断】/【未证实】。
5. 【推断】都附判别实验吗。
6. 有「互相印证 / 佐证」吗——有就删，换具体判别手段。
7. 报数字绑定场景 / 负载条件了吗。
8. 给分布和峰值而非只有均值吗（用户体感是峰值）。
9. 被排除项与依据写了吗。
10. 悬置项给可执行判别手段了吗——先过结案判据。
11. 每条解释旧观察的结论核对过时间轴吗（该变量在观察当时成立吗）。
12. 声称「口径吻合」时确认过独立测量链吗（同源不算交叉验证）。
13. 判「功能在跑」用的是 L3 实际交付层证据吗。
14. 写「唯一 / 首次 / 分界点 / 从未发生」了吗？写了校验三层覆盖：
    查询窗口 / 数据源保留起止 / 过滤条件（阳性对照亮 ≠ 范围够）。
15. 输出「下一步判别实验」前先过结案判据。
16. 「要复现的现象」写成操作性定义了吗（形态 / 父子关系 / 数量 / 存活时长 / 触发方式）。

## 硬规则

- **F1 三级标注**：【已证实】有原始数据或判别实验；【推断】附判别实验；【未证实】只有线索。
- **F2 禁止互证措辞**：未经验证的两个现象只能说「同时存在」。
- **F3 显式收回**：被证伪的结论写明作废，不静默修改。
- **F4 先读后断**：能读到的不推断；读不到才推断并标注。
- **F5 先校验单位**：时间看时区零点，容量看单位分母，日志看滚动规则。
- **F6 经得起 challenge**：写明证据来源、适用范围、反例、验证成本。
- **F7 不交付未验证的东西**。
- **F9 时间轴对齐**：禁止用事后才成立的条件解释更早的观察；核实不了留作未解释项。
- **F10 工具失败不得无处理进入下一步**：同因 2 次即熔断，下一步必须是换工具 / 换子任务 / 问用户 / 报告阻塞之一。

## 熔断检查（执行中）

任何工具调用失败，立刻自问：上一动作失败的这一步，与上是同一动作吗？是 = 正在 loop，STOP。
换工具 / 换子任务 / 问用户 / 报告阻塞，四者皆非 = 违规。

## 三层判据

| 层 | 含义 | 能证明什么 |
| --- | --- | --- |
| L1 设置 / 开关 | 用户或系统允许 | 什么都不证明 |
| L2 服务已启用 / 已注册 | 通道搭好了 | 只证明「不是被禁止的」 |
| **L3 实际交付** | 真的在出数据 | **只有这层能证明「在干活」** |

用任何代理标志前先标定它在哪一层；没标定就别下「在 / 不在工作」的判断。

## 高频翻车点与判别动作

| 翻车方式 | 判别动作 |
| --- | --- |
| 相关性当因果 | 改变 A，B 会跟着变吗？没做过标【推断】 |
| 只读半截数据 | 字段取值区间完整吗？缺失段是重启还是休眠？ |
| 用均值回应体感 | 切等长窗口，比分位数与峰值 |
| 新条件解释旧观察 | 该变量在旧观察发生时成立吗？先对时间轴 |
| 同源读数当独立交叉验证 | 两条独立测量链，还是同一链的原始值与积分？ |
| App 前台代替「功能在跑」 | 有没有功能级标志？前台 ≠ 功能启用 |
| 「开着的」当「在干活的」 | 证据停在哪层？只有 L3 能证明 |
| 功耗反推模块工作 | 空转 vs 干活功耗分得出来吗？分不出就别用 |
| 跨口径比较 | 同一把尺子量的吗？不是先做口径标定 |
| 单点峰值当阈值 | 采样间隔内自然波动多大？用驻留时长代替峰值 |
| 窗口设窄当数据不够 | 数据源最早回溯到哪？阳性对照亮只证明方法能打出 |
| 现象形态变了沿用旧判据 | 形态 / 父子 / 数量 / 存活 / 触发逐项还一样吗？变了换题 |

## 结案检查（收尾前）

```
[ ] 结论错了用户会有感知吗？没有 → 影响面为零
[ ] 根因在第三方闭源组件内部、本机证据源覆盖不到？是 → 已到可归因边界
[ ] 已有合理推定（机制自洽 + 独立数据 + 无明显反例）？是 → 低代价可高度盖然性收口
[ ] 旧现象已无法复现或形态变了？是 → 旧题结案，再出现按新问题立题
```

命中 ≥1 → 提出结案并等用户决定；4 条全中 → 直接停，不再给下一步实验。
结案不等于省掉分级标注。**不适用**：不可逆操作 / 安全隐私 / 对外发布 / 用户明确要 root cause。

## 冲突处理

用户感受 vs 数据冲突时，先怀疑我取错窗口（窗口长度、负载混杂、单位时区、均值 vs 峰值），
再怀疑用户记错。用户的纠正几乎每次都成立，优先复测，不用新解释消化反例。

## 反例

- ❌ 没标级就写结论；【推断】不附判别实验。
- ❌ 写「互相印证 / 佐证」；同源读数当独立验证。
- ❌ 用事后条件解释旧观察。
- ❌ 停在 L1 / L2 就宣布「功能在跑」。
- ❌ 工具失败无处理进入下一步；同因连败两次仍重试。
- ❌ 只给下一步实验、不过结案判据。
