# 测试证据与产物纪律

## 这是什么

测试与调查中的职责边界、证据优先级、失败归类、覆盖反查、产物落盘与缺陷闭环。

## 什么时候用

确认问题、收敛责任端、写提单材料、审测试证据时。

## 怎么装

把本目录放到你所用 agent 的 skill 目录（各产品位置不同，按其文档操作）。
纯文档，无依赖。

## 最小例子

遇到失败先判复现性，再把责任端归到主类（入口配置 / 数据 / 鉴权 / 工具链 / 环境 / 产品 / 第三方 / 脚本误报），拿不出证据时标「证据缺口」不按成功闭环。

## 文件说明

- `SKILL.md` — 方法本体：范围、完成判据、WHEN→THEN、硬规则、资源索引、反例
- `GLOSSARY.md` — 本方法用到的专有术语
`references/` — 边界、产物、覆盖、失败归类、提单
