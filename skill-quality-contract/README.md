# skill 质量门禁

## 这是什么

校验一个新产出的 skill 是否够格：S1–S5 质量判据与 G1–G9 交接自检两组都通过才放行。
可选生成无答案泄漏的材料包，供外部独立评审使用。

## 什么时候用

一个 skill 写完后要判断质量；需要生成独立评审的交接材料；核查一份评审是否可信。

## 怎么装

把本目录放到你所用 agent 的 skill 目录（各产品位置不同，按其文档操作）。
带 `scripts/`，需 Python 3.9+，只用标准库。`build_handoff.py` 的外部校验脚本路径由环境变量配置，详见 SKILL.md 的依赖声明。

## 最小例子

对刚写完的 skill 逐项核 S1–S5 与 G1–G9，两组都过即放行；
若要外部独立视角，用材料包生成脚本构造无答案泄漏的输入，请评审方在独立会话里只凭材料包判断。
