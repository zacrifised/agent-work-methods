# 场景契约

## 1. 适用范围

本 skill 适用于任何已落盘的 skill：先跑质量门禁（S1–S5 + G1–G9），
需要独立复核时生成无答案泄漏的材料包。不按 skill 的用途分类，不强制或禁止任何后续动作。

## 2. 场景边界

| 不覆盖 | 说明 |
| --- | --- |
| 用产出的 skill 生成下游产物（test case、排查结论、报告等） | 不在门禁职责内 |
| 尚未落盘、磁盘上没有文件的方案 | 不在本场景内 |
| 复评本 skill 自己 | 判据外部于被评对象 |
| 复核方的启动方式 | 由使用方决定，本 skill 只提供材料包与 prompt |

## 3. 材料包要求

- 无答案泄漏：不含结论 / 裁决 / 改动清单 / 处置状态。
- 自足：审核对象、判据、排除项、路径、禁止读取项齐全。
- 复核方在独立会话中执行（机制见 `expert-mechanism.md`）。

## 4. 裁决回流

1. 标 `external_unverified`：第二方结论是二级输入，只提取结构，不直接改成结论。
2. **只裁分歧**；一致项不额外论证，不写「双方一致」当支持证据；
   整轮收工仍须 S1–S5 全过且 G1–G9 无阻断。
3. 分歧逐条写证据裁决；需使用方决策的项给**选项 + 建议及其依据 + 完整出处**。
4. 未启动独立复核时如实写「未执行独立复核」，不代为宣布通过。
