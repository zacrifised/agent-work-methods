# 分歧裁决

## 分歧分类

| 类 | 定义 | 处置 |
| --- | --- | --- |
| 事实分歧 | 对同一实物有不同描述 | 回原始工件核，读回后定 |
| 判据分歧 | 对「什么算通过」理解不同 | 回判据定义，缺操作定义的补定义 |
| 覆盖分歧 | 一方查到另一方没查到的面 | 补查该面，记录扩域结果 |
| 推理分歧 | 同一证据导出不同结论 | 标悬置，写判别实验 |

## 裁决顺序（能停在哪层就停在哪层）

1. 一手证据：完整绝对路径 + 行号 + 原文片段。
2. 可复现实验：给出命令与预期两侧返回。
3. 判据定义：回操作定义，不改判据迁就结论。
4. 仍不能定 → 标悬置，列判别实验与所需观察量。

## 提取结构（第二方结论只按这三项落地）

| 字段 | 内容 |
| --- | --- |
| 状态 | `leading` / `suspended` / `weakened` |
| 证据缺口 | 缺哪份一手材料、缺哪个观察量 |
| 下一步判别检查 | 可检验的动作与预期两侧返回 |

第二方结论标 `external_unverified`；不直接改成本方结论。

## 报出判读（有效性对照）

| 项 | 判据 |
| --- | --- |
| 位置 | 完整绝对路径 + 行号；无行号对象用「路径 + 对象标识 + 内容摘要」 |
| 类别 | 词面泄漏 / 处置状态 / 非词面泄漏 |
| 原文片段 | 一字不改的片段 |

三者缺一不算报出。**3 条全报出且非词面那条必须报出**；未达标判整轮复核无效，
重选第二方形态后重跑。缺陷清单与凭证不进入第二方视野。

## 术语与状态词映射

本 skill 统一称**第二方**；「审核方」是第二方执行复核时的角色，
「独立执行方」是复算证据的角色，三者指同一实体。

| 提取状态 | 台账「结果」列 |
| --- | --- |
| `leading` | 采纳 |
| `suspended` | 悬置 |
| `weakened` | 否决（附保留条件） |

## 硬规则

- 否决优先于采纳：能证伪的一条先处理，不用多数意见覆盖。
- 一致项不额外论证，不写进结论当支持证据；
  一致项放行**仅在有效性对照 3 条全报出、且非词面那条必报之后成立**。
- 第二方结论标 `external_unverified`；只提取结构，不改成结论。
- 需用户决策的项给选项 + 建议及其依据 + 完整出处。
