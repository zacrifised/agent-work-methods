# 方法论内核

## 这是什么

一组跨领域通用原则的单一真源：观测、实验、结论、结案、进化。

## 什么时候用

两套方法论口径冲突时；要判断结论形态、证据方向、何时结案、是否晋升一条规则。

## 怎么装

把本目录放到你所用 agent 的 skill 目录（各产品位置不同，按其文档操作）。
纯文档，无依赖。

## 最小例子

接到「某功能通不通」的问题：正向信号（接口 200）只能排除该节点不是断点，不能宣布通；只有端到端能宣布通。

## 文件说明

- `SKILL.md` — 方法本体：范围、完成判据、WHEN→THEN、硬规则、资源索引、反例
- `GLOSSARY.md` — 本方法用到的专有术语
`references/` — 观测 / 实验 / 结论 / 结案 / 进化五组原则
