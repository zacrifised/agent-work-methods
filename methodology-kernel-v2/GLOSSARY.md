# 术语说明

本文件只解释本 skill 正文里出现的专有词；按正文顺序不必全读，遇到不认识的词回来查。

**agent** — 执行任务的 AI 助手，本文件的使用者。
**skill** — 一份可加载的工作方法说明，规定何时用什么动作。
**独立第二方** — 与产出方信息隔离的复核者（人或另一个 agent），不知道产出方的结论和推理过程。
**判别实验** — 一次只改变一个变量的受控实验，结果能同时改变多个候选解释的可信度。
**阳性对照** — 用一个确定存在 / 确定会触发的对象跑同一条管道，确认方法本身有效。
**阴性对照** — 用一个确定不存在 / 不会触发的对象跑同一条管道，确认方法不会误报。
**盲读** — 在看不到原始输入的前提下判断文本或结论，避免「记得答案」污染判断。
**E2E** — 端到端：从用户真实入口走到可见结果，只有它能宣布「通」。
**P0–P18** — 本套方法论的原则编号，按主题分组：观测 / 实验 / 结论 / 结案 / 进化。
**G1–G9** — 闸门编号：触发条件 → 机械动作，与原则号一一对应。
**SSOT** — 单一真源：同一事实只在一处定义，其余位置只放指针。
**RCA** — 根因分析；本套方法不要求每次都闭合到唯一根因。
**机制声明门** — 宣称「机制是 X」之前，先找一个本应共享该原因却无症状的对照组。
**似然比** — 同一条证据在两个互斥假设下的出现概率之比；接近 1 表示这条证据几乎没有判别力。
**假设台账** — 把候选解释、证据、更新与下一步实验写成一张可追溯的表。
**P16** — 结案判据：影响面 / 可归因边界 / 合理推定 / 现象是否已变。
**P18** — 存在性结论的覆盖校验：阳性对照亮只证明方法能打出数据，不证明查询范围够。
**L0/L1/L2** — 本内核的三层结构：L0 通用原则、L1 领域流程、L2 案例与实测。
