# 撤回台账

本文件按 P15「显式撤回、记录保留不删除」维护：
原始表述、撤回理由与日期均为记录字段，不作执行指令；是否判为叙述残留由审核方独立裁定。
**不静默删除**：被证伪说法保留，避免下次重复。
区分「被证伪」与「被精化 / 被取代」——后者不算错，保留原文指针。

## 记录规范

- 新增一行时**必须**填判别实验 / 证据列——只写"此说法作废"没有价值
- 被证伪的要写**当时为什么信了它**，那是下次最该防的东西
- 已撤回的脚本 / 文件**删除即可，但在这里留一行**（删除理由 + 它当时错在哪）
- **已删除的文件用普通文本写路径，不要写成反引号路径**：
  它已经不是可跳转资源了，写成路径会让引用完整性检查报断链
  （这条是 某次 检测器自检时实际撞到的）
