# 分档与升级

## 选型

按影响半径选，不看改动行数。影响半径用引用 / 依赖搜索得到，列出受影响的面。

| 档 | 检查面 | 成本量级 |
| --- | --- | --- |
| L0 冒烟 | 改动点加载 / 运行 / 产出；语法与依赖 | 秒级 |
| L1 定向 | L0 + 直接调用方 + 影响半径内的面 | 分钟级 |
| L2 关联面 | L1 + 旁路功能 + 观测 / 自动化 | 十分钟级及以上 |

## 升级到 L2 的条件（命中任一）

1. 改的是公共层 / 被调用方多。
2. 涉及持久化或外部副作用。
3. 不可逆，或没有灰度。
4. 改动触及日志 / 指标 / 告警 / 自动化通道。
5. Q1 或 Q2 出现任一未解释的差异。

## 降级条件

仅当同时满足：单点改动、无调用方、可随时回滚、无持久化、影响半径已列全。
降级理由写进验证报告。

## 假通过形态（动手前逐条排除）

| # | 形态 | 排除动作 |
| --- | --- | --- |
| 1 | 只看状态码 | 补正向观测值 |
| 2 | 关键路径之外 | 按引用搜补调用方 |
| 3 | 补偿机制抹平 | 关掉补偿再跑一次 |
| 4 | 自愈后指标归零 | 看原始事件计数，不只看当前值 |
| 5 | 检测器抓不到 | 注入已知故障 |
| 6 | 基线过期 | 核基线时间与路径 |
| 7 | 副作用未清理 | 写还原确认 |
| 8 | 观测通道被改哑 | 把通道列入 Q2 |
| 9 | 预演当验证 | 改后必再跑一次 |
| 10 | 无基线写「没发现」 | 写「未覆盖」 |
