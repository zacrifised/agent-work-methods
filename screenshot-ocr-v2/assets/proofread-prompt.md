# 语义校对提示词模板（盲读）
实测效果：13 处形近替换 **13/13 命中且改对，0 误报**；
中把握档另命中 4/5 的删字（能定位"这里坏了"，但补不回准确字形）。
## 三条不可省略的约束
1. **不给原文、禁止查原文。** 一旦读者能看到（或搜到）原文，就不是校对而是回忆，
   测出来的召回数字是假的。这是本方法唯一的质量隐患。
2. **明确排除"不成词的合法单字"。** 中文里 的/了/是/在/我/水/鱼/看 本来就不成词，
   缺这条时输出被大量假阳性淹没（正确文本里 36% 的汉字位置都不成词）。
3. **要求分"高/中把握"两档。** 高把握档是可以直接采纳的；中把握档多半是
   原文自身的问题（作者口语写法、原文用典错误）或 OCR **删字**，需要再判读。
## 模板
```
你是一名中文校对。下面这段文字是【一张图片经 OCR 识别后的输出】，
因此里面可能存在少量【识别错字】（形近字被替换，例如低频字被换成常见字）。
【重要约束】
1. 你没有原文，也绝对不要去猜测或搜索这篇文章的出处、作者、原始版本。
   只依据这段文字本身的汉语语感来判断。
2. 不要修改标点、不要润色、不要评价文风。你的唯一任务是找出被 OCR 认错的字。
3. 判断标准：读句子时，某个字让所在的【词】不成立、或让整句在这个位置上
   "不像汉语"。例如某个双音节词其中一个字被换掉后不再是词。
4. 注意：中文里大量单字（的、了、是、我、在、水、鱼、看……）本来就不成"词"，
   不要把这些当作可疑。
5. 原文作者个别用词可能偏口语或生硬，那不算 OCR 错误，不要报。
【输出格式】先用一行说明你通读后认为"读不通/不成词"的位置总数，然后逐条列出：
<可疑字上下文(左右各取6~10字)> | 可疑字 | 应改为 | 你的把握(高/中)
如果某处你拿不准但觉得别扭，也列出来，把握标"中"。
最后单独一行写"高把握共 N 处 / 中把握共 M 处"。
以下是待校对的文本（约 NNNN 字）：
<OCR 全文>
```
## 结果怎么用
- **高把握** → 直接采纳（实测精度 100%）。
- **中把握** → 逐条人工/再判读，重点看是不是 OCR **删字**
  （读者会指出"这里断了"，但补的字常不对，此时回图做字形复核）。
- 读者指出但**原文确实如此**的（如作者写"呆会"、用典写错），
  不要改文本，作为"原文问题"单独报告。
## 边界（别高估这个数字）
- 样本量 n=1（1578 字散文，18 处错误）。散文的词汇冗余度高，
  **PRD/表格/代码/专名密集文本**的召回大概率会更低——那些地方"不成词"是常态。
- 只验证了替换类错误的精度；增删类只能定位，修复要靠字形复核。
