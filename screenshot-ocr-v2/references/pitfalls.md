# 已实测无效 / 已踩过的坑
动手前先扫一遍这张表——下面每一条都花过实测时间，重做一遍纯属浪费。
## 无效手段
| 尝试 | 结果 |
|---|---|
| 整图 3× 放大后重跑 | **更差**：97.15%，检测被过分割（35→44 行） |
| 固定检测框、只放大识别输入 1.5/2/3× | **零增益**：98.80–98.86% |
| 同引擎 4 种配置互相比对投票 | **无效**：4 次结果之间只差 2–5 字 |
| 等距网格做字形模板匹配 | **不可靠**：对齐误差 > 字形差异 |
| **按 OCR 置信度排序复核** | **判别力为 0**：行置信度 vs 行错误数 **Pearson r = 0.001**。错误最多的那行置信度 0.9566，是全文最高；最低那行（0.6276）反而是对的。要覆盖 81% 的错误得复核 67% 的全文 |
| **纯词典"不成词"检测自动改字** | **灾难**：628 处改动里 **605 处误改**，准确率 98.86% → **60.20%**（`的→料`、`我→提`、`了→开`）。元凶是"词典补全"候选——`材`+`的` 永远能凑出`材料`。**脚本已删除，不要重建** |
| **可疑位排序 + 高频词打分** | **无效**：召回@Top100 只有 **1/13**，榜首全是 `一开一合→一开一个`、`我会→我个` 这类胡改 |
| 让纯词频语言模型自由改写 | **翻车**：把"刀俎"改成"刀法"（词频更高），还大面积删字（1573 → 1478），CER 1.14% → 7.22% |
放大与同引擎投票无效：OCR 错误是**确定性偏差**不是随机噪声。
放大不改变模型的表征偏差；投票只能过滤随机噪声。
**要发现这类错误，必须引入架构不同的信息源**（见 `arbitration.md`）。
## 三个认知陷阱
1. **不要让纯词频语言模型自由改写。**
   纯词频缺字形约束，只适合"成词/不成词"这类**二值**判断，不适合同长度替换。
2. **人眼和模型犯同一类错。**
   盯着模糊的字看会**脑补成自己认识的字**（熟悉度偏误）——实测中某个字被自己读成了"响"。
   所以"交给人工复核"**不能**自动修掉这类错，必须显式做无先验比对。
   **人眼判读小字/生僻字要标为弱证据**，不与量化数据同权重。
3. **最该防的不是漏字。**
   漏字（实测 5/18）靠语义校对也能定位（中把握档命中 4/5）；
   **换成常用字之后的形近替换**（13/18）才是真正危险的——字形比对抓不到、
   置信度抓不到，只有语义读者能抓到（实测 13/13）。对 PRD 这类文档尤其如此。
   判据是**不成词**，即读不通，只是读者会自动脑补成认识的词。）
## 一处需要留意的措辞陷阱
讨论 OCR 错误时不要说"替换后读起来通顺，所以语义校对抓不到"。
**错字基本不成词，是读不通的**；抓不到它们的真实原因是定位判据噪声太大
（见 `semantic-proofreading.md` 的似然比表），不是语义分析无效。
