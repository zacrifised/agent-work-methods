# 答案清单与材料包自检

产出方交付前必读；审核方复核材料包时按同一套判据。

## 1. 答案清单（绝对不进材料包 / prompt）

| 类别 | 泄漏后果 |
| --- | --- |
| 主 agent / 历次评审的**结论、裁决、挑刺判决书、改动清单、对话判断** | 复核退化成复述推理链 |
| 任何记着答案的**日志、台账、报告** | 同上 |
| 历次评审**脚本及其输出清单** | 含「哪些成立 / 哪些驳回」的元信息 |
| 任何记录**问题处置状态**的元信息（已修 / 已作废 / 已裁定 / 编号） | 审核方按既有裁决对齐 |
| 「已复核为中性 / 裁决结果记录在某处」这类**既成判断** | 自证中性也是判断 |
| 产出方对新 skill 的**自评分数 / 是否通过的自报** | 分数只诊断，放行由 S1–S5 决定 |
| 对话历史、记着答案的 workspace 日志 | 破坏无上下文会话 |

## 2. 5 类禁止项

**真源是 `scripts/build_handoff.py` 的 `FORBIDDEN_CLASSES` 常量**；本文件只放指针，不抄第 2 份列表。
脚本自动把 5 类写进材料包第 4 节，不依赖人工 `--forbid`。

**5 类必须全部写进材料包，不得改成「按需选取的清单」，也不得只写标题。**

## 3. 自检

改本 skill 任一文件后跑 `python scripts/verify_gates.py`，全过才交付；
任一 G FAIL 为链路阻断，放行仍按 S1–S5。
门禁项与判据见 `release-gates.md`，本文件不重复。

## 4. 出处粒度

每条问题固定给 **完整绝对路径 + 文件名 + 行号（如适用）+ 原文片段 + 一句人话「在问什么」**；
无行号对象用「路径 + 对象标识 + 内容摘要」，不编造行号；禁止只给编号或相对路径。
