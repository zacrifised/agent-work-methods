# 专家评审交接

## 这是什么

为独立专家生成一份无答案泄漏的材料包，并用清单式门禁验证交接链路。

## 什么时候用

产物完成要送独立专家评审；需要生成交接材料；核查一份评审是否可信。

## 怎么装

把本目录放到你所用 agent 的 skill 目录（各产品位置不同，按其文档操作）。
带 `scripts/`，需 Python 3.9+，只用标准库。`build_handoff.py` 的外部校验脚本路径由环境变量配置，详见 SKILL.md 的依赖声明。
## 最小例子

把待评对象目录交给材料包生成脚本，把产出清单放进禁止读取项，请专家在独立会话里只凭材料包判断；拿到结论后只裁分歧。
