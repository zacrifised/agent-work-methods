# 术语说明

只解释本 skill 正文出现的专有词；遇到不认识的词回来查。

**agent** — 执行任务的 AI 助手，本文件的使用者。
**skill** — 一份可加载的工作方法说明，规定何时用什么动作。
**独立第二方** — 与产出方信息隔离的复核者，不知道对方的结论与推理过程。
**判别实验** — 一次只改变一个变量的受控实验，结果能改变多个候选解释的可信度。
**case** — 测试用例：给定前提、步骤与期望结果的可执行描述。
**用例资产** — case 的持久化载体（通常是 Markdown），是后续生成断言与自动化脚本的真源。
**输入包** — 写 case 前综合的上下文：PRD、设计、评审记录、原型、澄清结论。
**覆盖索引** — 需求点与 case 的一一对应表，缺口不许静默通过。
**边界成对** — 每个边界条件写正反两侧（刚达到 / 刚超过）。
**断言 manifest** — 由 case 派生、供机器执行的断言清单；由下游环节生成，本 skill 不负责。
**E2E** — 端到端：从用户真实入口走到可见结果。
**SSOT** — 单一真源：同一事实只在一处定义。
**L1** — QA 中间层：机器可断言、零信任主断言。
