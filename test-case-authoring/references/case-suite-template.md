# 测试用例套件模板

本模板约定 case 资产的最小完整字段集。

目标：
- 保证输入真源、澄清口径、流程理解、覆盖关系、假设与不覆盖项都能被看到

## 4. 流程梳理

只在需要时提供，不要求每次都画完整大图。

可选形式：
- 流程图
- 时序图
- 结构化流程列表
- 局部流程梳理

建议结构：
1. 入口条件
2. 关键阶段 / 状态切换
3. 多角色 / 多端职责
4. 关键兜底 / 回退 / 异常分支
5. 与旧流程相比的变化点
