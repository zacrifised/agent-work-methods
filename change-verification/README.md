# 改动验证

## 这是什么

用最小成本回答两件事：改动真的生效了吗、有没有破坏已有行为。

## 什么时候用

改完配置、脚本、代码或文档后，交付之前。

## 怎么装

把本目录放到你所用 agent 的 skill 目录（各产品位置不同，按其文档操作）。
`scripts/check_detector.py` 需要 Python 3.9+，只依赖标准库。

## 最小例子

改完一个配置：先拿一个正向观测证明它生效，再跑一遍回归证明没破坏别的；无基线时写「未覆盖」而不是「已验证」。

## 文件说明

- `SKILL.md` — 方法本体：范围、完成判据、WHEN→THEN、硬规则、资源索引、反例
- `GLOSSARY.md` — 本方法用到的专有术语
`references/` — 两问、分级、检测器自检
