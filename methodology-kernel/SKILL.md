# 方法论内核（L0）

## 范围

覆盖：跨领域通用原则的单一真源（P0–P18）、原则冲突时的优先级、规则自进化闸门。
不覆盖：任何具体领域的操作流程；各 skill 引用本内核，不复制原则正文。

## 完成判据

- 引用本内核的 skill 只写指针，不复制原则正文
- 写结论前判证据方向（正向只能排除、负向才能定位、只有端到端能宣布通）
- 用代理指标前写明它覆盖不到的边界
- 宣称机制前做过反例搜索；「一致」不写成「互相印证」
- 候选关系已判（互斥 / 独立 / 因果链 / 包含 / 共因）才决定结论形态
- 判断「还追不追」走 P16–P18，不靠直觉
- 规则晋升满足五闸门；单次会话最多沉淀 3 条
- 长任务证据落盘、状态文件在阶段边界更新，中断后从状态恢复

## WHEN → THEN

**WHEN**：两个 skill 口径冲突 / 要写结论 / 判证据方向 / 升格规则 / 撤回说法 / 判断何时停。
**THEN**：
1. 查下方原则索引，定位适用原则编号。
2. 按「冲突时谁赢」定优先级（观测先于结论、总则覆盖操作层、结案不覆盖总则）。
3. 到对应 `references/*.md` 读四段式（一句话 / 判别问句 / 已知反例 / 谁在用）。
4. 规则变动走五闸门；写回后跑引用完整性 + 乱码 + 内容保全回归。
5. 长任务按「状态恢复」段落盘与恢复。

## 三层结构

| 层 | 内容 | 稳定性 | 谁来改 |
| --- | --- | --- | --- |
| **L0 本内核** | 跨领域通用原则 | 高 | 只能人工改 |
| L1 各 skill | 领域操作流程与规则 | 中 | 可自进化，走闸门 |
| L2 案例与实测 | 单次观察与数据 | 低 | 只作证据，不作规则 |

## 硬规则

1. **单一真源**：跨领域原则只在本内核写一次；各 skill 引用不复制。
2. **观测先于结论**：信号拿错时，结论纪律再严也救不回来。
3. **总则覆盖操作层**：P8–P11 冲突时压过领域 skill 的操作规则。
4. **结案不覆盖总则**：高代价决策仍回到 P10 排他标准，高度盖然性只在低代价区生效。
5. **规则变更走五闸门**：缺任一闸门不许落地；总则类（P8–P11）只能人工改。
6. **剂量控制**：单次会话最多沉淀 3 条新规则。
7. **撤回不删记录**：被证伪的说法写明作废并保留记录，供后续查是否复活。
8. **冲突回修**：本内核与其它 skill 冲突时以本内核为准，然后回来修那个 skill。

## 自进化：五道闸门

1. **晋升门槛**：≥2 次独立场景命中，才从「观察」升「规则」（同场景重复不算）。
2. **反例栏**：没写「不适用于」的规则不许晋级。
3. **衰减与复审**：长期未命中或被反例命中 → 降级或撤回，记录保留。
4. **硬核保护**：总则类（P8–P11）只能人工改；自进化只动操作层。
5. **改完必跑检测器**：引用完整性 + 乱码 + 内容保全回归（有基线才判得动）。

剂量控制：单次会话最多沉淀 3 条新规则。膨胀到没人读，比少记几条更糟。

## 长任务状态恢复

- 原始日志、大段命令输出、CSV、JSON、截图、证据摘录**默认落盘**；
  对话里只报路由判断、关键计数、高信号表格、覆盖缺口、产物路径。
- 每轮非平凡调查建目录时即更新 `investigation_state.json`（最小字段见下）+ 简短 `README.md`；
  compact / 中断 / 掉线后**从状态文件恢复，不从对话历史重建**。
- 恢复时只检查缺失源，不重读已落盘证据；先读摘要与聚合，原始数据只在需精确核验时打开。

`investigation_state.json` 最小字段：`task`（本次问题）、`sources`（已读源与路径）、
`findings`（已确认/已排除/悬置）、`artifacts`（产物路径）、`next`（下一步入口）。

## 冲突时谁赢

- 观测类先于结论类：信号拿错，结论纪律再严也没用。
- 总则（P8–P11）覆盖操作层规则。
- 结案判据（P16）不覆盖总则：高代价决策仍回到 P10。
- 本内核与其它 skill 冲突时以本内核为准，然后回来修那个 skill。

## 反例

- ❌ 两个 skill 冲突时各自改一份，而不回内核统一。
- ❌ 复制原则正文到领域 skill（必然分叉）。
- ❌ 正向信号当「通」的证据；代理指标当目标本身。
- ❌ 没判候选关系就并列多个 root cause。
- ❌ 用「一致 / 互相印证」代替分歧检验。
- ❌ 无反例栏的规则晋级；单次会话一次沉淀超过 3 条。
- ❌ 长任务靠对话历史恢复，而不是状态文件。
