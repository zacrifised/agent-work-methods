# 实验类原则（P6–P7）

## P6 判别实验优先于先验

**一句话**：**判别性 > 先验**。一次只改一个变量；
结果必须能**同时移动多个假设的权重**。

**判别问句**：做完这个实验，我会改变下一步做什么吗？不会 → 别做。
再问一句：这条证据是**只有 H 成立才该看到**的吗？是所有假设都预测得到 → 零价值。

**已知反例（三种）**：

1. 似然比 ≈ 1 的证据——真实，但零信息量（所有假设都预测得到它）。
2. **"再试一次"不是判别实验**：同样输入再跑一遍只能区分"必现 / 偶现"，
   区分不了原因。判别实验必须改变某个变量。
3. **一次改多个变量 → 结果无法归因**。这条不是建议，是判别实验的定义所禁止的。

**谁在用**：`排查方法论 skill` 主循环第 3、6 步与四条翻车规则之一。

## P7 信息价值 > 信息量

**一句话**：**不会改变决策的验证，做得再漂亮也是浪费**。
算的是**边际收益 vs 边际损失**，不是省不省钱。

**判别问句**：这个数据拿到手，我的**决定**会变吗？不变 → 不做。

**已知反例 / 正例**：

- 正例（边际分析）：去抖阈值 90 → 150ms，最多再捞 0.15/百次，
  却要冒吃掉 1.7/百次正常操作的风险——**边际收益为负**，所以不做。
  注意这是**边际收益 vs 边际损失**，不是"省钱"：它判断的是值不值，不是贵不贵。
- 反例：为了"数据更完整"去补一个不影响结论的指标；为了"验证更充分"
  去跑一个通过了也不会改变上线决定的用例。

**谁在用**：`排查方法论 skill` 外部先验的成本账、
`screenshot-ocr/references/model-selection.md` 的端到端成本账（276s vs 86s）。
